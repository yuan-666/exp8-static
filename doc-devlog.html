v2.2.0 重大更新
纯静态版本重构

将 Spring Boot + Thymeleaf 后端架构重构为纯 HTML/CSS/JS 静态版本，使用 localStorage 模拟数据持久化，适配 GitHub Pages 部署。

  • 移除后端依赖，全前端实现 CRUD
  • Glassmorphism 视觉风格统一
  • 模拟认证系统（localStorage）
  • 响应式布局优化
  • 新增开发日志与技术文档页面
